Five independent, single-purpose PowerShell (.ps1) utilities operating on a shared static frontend tree rooted at `frontend/patchkraze.com` (with subdirectories `products`, `collections`, `pages`, `blogs`, `policies`). Each script is self-contained: it reads/writes files via `[System.IO.File]::ReadAllText`/`WriteAllText` using UTF-8 encoding, applies regex-based transformations or HTTP calls, and prints progress counters. There is no shared library — cross-cutting concerns (base path, TLS 1.2 enforcement, error handling) are duplicated per script. Dependency direction is one-way: scripts consume the local filesystem and optionally call external services (`cdn.shopify.com` for image downloads, `hjnowvzxusjjyhxxgdji.supabase.co` REST API for seeding). Hardcoded Windows paths under `C:\Users\MOS\Desktop\New folder (2)\...` bind the scripts to a specific developer machine rather than being portable.
