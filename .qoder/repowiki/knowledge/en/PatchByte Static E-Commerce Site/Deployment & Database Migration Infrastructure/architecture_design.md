This leaf module centralizes deployment and database setup across two hosting platforms and one database provider. Netlify is configured via `netlify.toml`, which sets Node 18, publishes the `public/` directory, runs a custom `netlify-build.js` preprocessor, and declares all URL rewrites: permanent (301) redirects for renamed product/collection pages, clean-URL-to-.html passthroughs for products/collections/pages/blogs/policies, cart/checkout index routing, and proxy rules that forward `/cdn/*` paths to Shopify's CDN with `force=true`. The build script (`netlify-build.js`) copies selected assets from `frontend/patchkraze.com` into `public/`, explicitly skipping the nested `cdn/` folder while copying theme CSS/JS, fonts, and `frontend/js` so they are served locally. Vercel support is minimal via `vercel.json`: it points at an API function at `api/index.js`, includes only HTML, robots.txt, JS, and a subset of Shopify CDN assets, and rewrites every route to that function. `migrate-tables.sql` is a standalone Supabase SQL migration that adds columns (product slugs, prices, JSONB properties, customer/shipping fields, totals, status, contact fields) to `cart_items`, `orders`, `order_items`, and `contact_submissions`, then enables Row Level Security on each table with permissive `anon_*` policies allowing unauthenticated access for public-facing forms.
