The module is split into three layers. The runtime layer (`server.js`, `package.json`) runs an Express 5 app on Node ≥18 that serves the static site under `patchkraze.com/` and exposes `/api/create-payment-intent` and `/api/stripe-config` for Stripe checkout; it also proxies any missing `/cdn/*` requests back to Shopify's CDN via `https.get`. A catch-all route rewrites clean paths like `/products/foo` to `patchkraze.com/products/foo.html` or `.../index.html`, with explicit permanent/temporary redirect tables for renamed content. The presentation layer is a Shopify Dawn theme (theme id `38`) whose HTML templates live in `patchkraze.com/` (pages, products, collections, blogs, policies) and reference CSS/JS from `cdn/shop/t/38/assets/`. The theme uses an importmap (`@theme/*`) to load small ES modules — each file implements one UI concern (cart drawer, product form, media gallery, variant picker, etc.) — built on a shared `Component` base class in `component.js` that provides declarative shadow DOM, `[ref]` binding, and event delegation via `on:<event>` attributes. Vercel deployment is configured via `vercel.json` using the `@vercel/node` builder with an include list of only the needed HTML, JS, and theme assets.
