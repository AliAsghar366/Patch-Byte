The workspace is organized into three sibling modules under the root: `frontend/` (Shopify Dawn theme plus an Express/Node server handling Stripe intents and URL routing), `scripts/` (PowerShell utilities that download CDN assets, rewrite HTML, inject client scripts, rebrand text, and seed product metadata into Supabase), and `infra/` (Netlify/Vercel platform configs and a Supabase migration script). The root `package.json` declares only the runtime dependencies needed by the frontend Express server (`express`, `stripe`, `dotenv`) and exposes `npm start` to launch it; all other tooling runs via PowerShell scripts or CI/deployment pipelines rather than npm scripts. There is no shared library between children — they communicate through the filesystem (static HTML/CDN assets produced by `scripts/` consumed by `frontend/`) and through Supabase tables created by `infra/` migrations and seeded by `scripts/`.
